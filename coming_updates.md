# Zenith Plans & Credit System

## Vision

Zenith no es un generador automático de juegos.

Zenith es un asistente de desarrollo para Roblox Studio diseñado para ayudar a creadores a construir, analizar, corregir y mejorar sus proyectos.

El objetivo principal no es reemplazar al desarrollador, sino convertirse en un compañero de trabajo capaz de entender proyectos reales, investigar problemas y ayudar a resolverlos mediante herramientas conectadas directamente con Roblox Studio.

Zenith no promete crear juegos completos automáticamente ni garantizar resultados sin supervisión.

Zenith ayuda al creador a trabajar mejor.

---

# Free Mode

## Objetivo

El modo gratuito permite que cualquier creador pueda probar Zenith y experimentar cómo funciona un agente conectado a Roblox Studio.

El objetivo del modo Free no es bloquear al usuario rápidamente, sino permitir que conozca el valor de Zenith antes de decidir si necesita una suscripción Pro.

---

# Free Credits

Free Mode tendrá un sistema de créditos limitado.

Ejemplo inicial:

- 15 créditos disponibles.
- Recuperación mediante tiempo.
- Posibilidad de ganar pequeñas cantidades mediante Zenith Trials.

Los créditos no representan mensajes.

Los créditos representan trabajo realizado por Zenith.

---

# Free Assistant Model

Free Mode utilizará un modelo optimizado para mantener costos controlados.

El modelo será seleccionado buscando un equilibrio entre:

- buena comprensión de código;
- seguimiento de instrucciones;
- uso correcto de herramientas;
- estabilidad;
- costo por ejecución.

Free Mode no utilizará necesariamente el modelo más potente disponible, pero debe ofrecer una experiencia suficientemente buena para que los usuarios puedan confiar en Zenith.

---

# Free Features

Los usuarios Free podrán utilizar:

## Project Understanding

- Ver Explorer.
- Buscar objetos.
- Revisar estructura del proyecto.
- Consultar información básica.

Estas acciones tendrán poco o ningún consumo porque no representan un trabajo pesado.

Ejemplos:

- "Busca este objeto."
- "¿Existe este script?"
- "Muéstrame dónde está este sistema."

---

## Script Assistance

Acciones como:

- leer scripts;
- explicar código;
- encontrar posibles errores;
- analizar pequeños problemas.

Tendrán un consumo bajo dependiendo del tamaño y complejidad.

Ejemplo:

Leer un script pequeño:

0.2 créditos aproximadamente.

---

## Workspace Help

Zenith puede ayudar con tareas como:

- encontrar errores;
- explicar sistemas;
- crear pequeñas modificaciones;
- guiar al usuario paso a paso.

Las tareas grandes tendrán un consumo basado en el trabajo realizado.

---

# Zenith Trials

Cuando un usuario llega a 0 créditos, podrá utilizar pequeños juegos dentro de Zenith para recuperar una cantidad limitada.

El objetivo no es reemplazar un plan Pro.

El objetivo es evitar que el usuario quede completamente bloqueado.

Ejemplo:

Juego:
Zenith Dodge

Sistema:

- superar rondas;
- evitar obstáculos;
- completar desafíos.

Recompensa máxima:

+5 créditos diarios.

Los usuarios no podrán obtener créditos infinitos jugando.

# Pro Mode

## Objetivo

Zenith Pro está diseñado para creadores que necesitan trabajar constantemente en proyectos más grandes.

Pro no significa solamente más mensajes.

Pro significa más capacidad de trabajo.

---

# Pro Credits

Ejemplo:

Máximo acumulable:

150 créditos.

Regeneración:

+25 créditos diarios.

Sistema:

Día 1:
25 créditos

Día 2:
50 créditos

Día 3:
75 créditos

Día 4:
100 créditos

Día 5:
125 créditos

Día 6:
150 créditos máximo

Los créditos no aumentan indefinidamente.

---

# Pro AI Model

Pro utilizará modelos superiores para tareas más complejas.

Modelo inicial planeado:

- OpenAI GPT-5 Mini

Uso:

- análisis profundo;
- debugging;
- tareas largas;
- planificación;
- comprensión de proyectos grandes.

Los modelos más potentes serán utilizados cuando realmente aporten valor.

Las tareas simples no deben gastar recursos innecesarios.

---

# Pro Features

Incluye:

## Advanced Workspace Agent

Zenith puede trabajar con tareas completas:

Ejemplo:

Usuario:

"Investiga por qué mi AnimationServe falla cuando equipo este objeto."

Zenith:

1. Revisa Explorer.
2. Encuentra AnimationServe.
3. Lee el código.
4. Busca conexiones relacionadas.
5. Revisa GUIs o sistemas conectados.
6. Identifica la causa.
7. Propone o aplica solución.
8. Verifica resultados.

---

## Project Memory

Pro tendrá memoria avanzada del proyecto:

Puede recordar:

- estructura del Explorer;
- sistemas existentes;
- scripts importantes;
- arquitectura;
- conexiones entre objetos.

El objetivo es evitar reconstruir todo el contexto en cada conversación.

---

## Longer Tasks

Pro permitirá tareas más largas:

Ejemplos:

- crear sistemas completos;
- modificar múltiples scripts;
- investigar errores complejos;
- optimizar proyectos.

---

# Credit Usage System

Zenith no cobrará por hablar.

Zenith cobrará por trabajo realizado.

Ejemplos:

## Bajo consumo

Buscar objeto:

0 créditos.

Leer script pequeño:

0.2 créditos.

Ver Explorer:

0 créditos.

---

## Medio consumo

Modificar un script:

Depende del trabajo.

Crear una GUI:

Depende de complejidad.

---

## Alto consumo

Sistemas completos:

Depende de:

- tiempo utilizado;
- cantidad de herramientas ejecutadas;
- archivos modificados;
- complejidad del problema.

---

# Workspace Experience

Zenith debe sentirse como un compañero de desarrollo.

No debe funcionar como un chatbot tradicional.

Ejemplo:

Usuario:
"Crea una GUI de tienda."

Zenith muestra:

🌳 Revisando Explorer

📄 Buscando sistemas existentes

🎨 Creando interfaz

⚙️ Conectando lógica

🧪 Verificando

✅ Completado

---

# Important Product Rule

Zenith nunca debe prometer crear juegos completos automáticamente.

Zenith ayuda al creador.

El usuario mantiene el control del proyecto.

La meta no es reemplazar desarrolladores.

La meta es hacer que desarrollar sea más rápido, claro y accesible.

---

# Final Goal

Crear un asistente de Roblox Studio que los usuarios puedan usar y confiar.

No un chatbot con respuestas.

No una herramienta que solamente genera código.

Un verdadero espacio de trabajo inteligente para creadores.
