Zenith está entrando en la fase V1 Agent Tools. El objetivo NO es simular capacidades. Cada herramienta debe funcionar realmente en Roblox Studio mediante Plugin API. No agregues comandos inventados ni placeholders.

Cada herramienta debe:

Existir en buildSystemPrompt().
Existir en executeCommand().
Tener validación de argumentos.
Devolver JSON consistente:
{
  "success": true,
  "data": {},
  "error": null
}

o

{
  "success": false,
  "error": "message"
}

El objetivo de Zenith V1 es permitir que una IA:

Explore proyectos.
Lea scripts.
Modifique scripts.
Cree GUIs.
Cree sistemas completos.
Detecte arquitectura existente.
Mantenga contexto del proyecto.

Zenith NO debe afirmar que hizo cambios si Roblox Studio no confirmó:

success=true

El objetivo final es que Zenith funcione como un copiloto real para Roblox Studio similar a Cursor, pero integrado directamente dentro del Editor.
