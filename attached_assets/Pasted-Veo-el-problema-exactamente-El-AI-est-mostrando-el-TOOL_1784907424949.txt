¿Por qué el AI mostraba el TOOL: como texto?
El chat tiene 2 modos:

Con plugin conectado → agentLoop → detecta TOOL:, lo ejecuta en Studio
Sin plugin → plainStream → solo texto, sin ejecución
El TOOL: que viste como texto = el plugin no estaba conectado cuando enviaste el mensaje. El AI lo hacía de memoria aunque no tenía herramientas disponibles.
